# YoWall
YoWall is a lightweight macOS menu bar app that brings your desktop and lock screen to life with your favorite videos or GIFs. Easily switch visuals, pause on a frame to save power, and run over full-screen apps smoothly.Easily personalize your Mac today!

This is the first version of the app uploaded[V.1] 

When you quit the app it either keeps the last frame of the wallpaper as the main wallpaper
or keeps the wallpaper that you saved in settings
